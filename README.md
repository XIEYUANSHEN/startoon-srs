# StarToon SRS — 仿崩铁风格 MMD 三渲二插件

面向 MMD 模型、以还原《崩坏：星穹铁道》卡通渲染观感为初衷的 Blender 三渲二（Toon）插件：
一键把 PMX 材质转成"卡通明暗 + 分类独立调色 + 反法线描边 + 眼透"的仿崩铁渲染方案。

## 环境

- Blender 4.2+ / 5.x（在 5.2.2 LTS 上开发验证）
- 依赖 [mmd_tools](https://github.com/mmd-blender-org/mmd_tools)（导入 PMX、生成描边壳）

## 安装

1. 把 `startoon_srs/` 放入 Blender 插件目录（`.../scripts/addons/`），或作为扩展安装。
2. 偏好设置里先启用 `mmd_tools`，再启用 `StarToon SRS`。
3. 3D 视图按 `N` → `StarToon SRS` 面板。

## 使用流程

1. 用 mmd_tools 导入 `.pmx` 模型。
2. 选中模型网格 → 面板点「一键三渲二」。
3. 在「皮肤 / 面部 / 头发 / 衣服 / 眼部」各标签下按类别调明暗、粉嫩、阴影参数。
4. 「亮度(全局)」调灯光能量/缩放/保底；旋转 `HSR_SunLight` 实时改阴影方向。
5. 「描边」开关与粗细/颜色；「眼透(仿崩铁)」调被刘海遮挡的眉眼混回。

## 核心架构

- **虚拟日光**：材质内 `dot(着色法线, 太阳方向)` 直接驱动 toon 明暗色带。太阳方向取
  `HSR_SunLight` 的世界朝向，由 depsgraph 处理器写入 `driver_namespace`，各材质用 SCRIPTED
  驱动读取（每角色可各绑一盏灯）。转灯即实时改阴影，不受场景其它灯光/环境光干扰。
  （旧版 GN 写顶点属性、以及 Diffuse→ShaderToRGB 读真实灯光两条路均已废弃。）
- **分类独立参数**：皮肤/面部/头发/衣服/眼部各一套完整的明部、暗部、阴影参数，互不影响。
- **EASE 多级阴影**：多级 EASE 渐变带，「阴影分界 / 过渡宽度」控制暗部范围与软硬。
- **描边**：复用 mmd_tools 的 Solidify 反法线壳（inverted hull），按 PMX 每个材质的
  `enabled_toon_edge / edge_color / edge_weight` 生成，只在轮廓显示。当算子在部分环境
  静默失败时，插件有纯 Python 的确定性兜底，逐字段对齐算子输出。
- **眼透（仿崩铁）**：眼周材质写 `透视 / 透明` 两个 AOV，合成器把被头发挡住的眉眼混回；
  头发保持 BLEND 不写深度，门控按头骨朝向限制水平可见角。零运行时开销。
- **半透/纱**：纱类材质走平光自发光旁路，避免薄双面法线被硬阴影压成死黑。

## 已知限制

- **多角色眼透门控**：眼透门控目前依赖单一全局头骨朝向（`_find_head_bone` 取场景第一个
  骨架），多角色同框时非主角色的门控会跟错头骨。单角色场景正常。
- **材质级覆盖易失**：`set_material_param` 的覆盖存在内存字典里，不随 .blend 保存，且会被
  下一次 `update_toon_params` 用分类值覆盖。
- **预设不含分类参数**：`preset.save_preset` 只序列化顶层属性，分类参数未纳入。
- **analyze 规则引擎半废弃**：`analyze.py` 的建议写回的属性当前面板不一定存在，规则基本空转。
